# Fintara brand assets

Source of truth for the Fintara mark, derived from the "Fintara" Canva brand
kit (front-facing fox + upward arrow, navy/teal/mint — matches
`web/src/lib/styles/tokens.css`). Favicons served by the app live in
`web/static/`; these are the raw brand assets for docs, marketing, and
anything not served at runtime.

- `logo-icon.png` — icon-only mark, transparent background, for light
  surfaces.
- `logo-icon-reversed.png` — white/teal mark, transparent background, for
  dark surfaces.
- `logo-horizontal.png` — icon + wordmark lockup, transparent background.
- `social-preview-og.png` — 1280×640, upload as this repo's GitHub social
  preview under Settings → General → Social preview (no API for this,
  UI-only).
- `brand-board.png` — one-page reference: palette, type, logo usage on
  light/dark.
